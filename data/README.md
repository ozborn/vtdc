# Criteria knowledge base

Place future versioned criterion specifications, taxon profiles, and assessment
instances here. The scaffold deliberately contains no claimed ICTV rule records.
Core ontology builds do not ingest this directory.

Each curated specification/profile should record the applicable ICTV release,
taxon scope, target rank, method and version, comparison region, comparator,
threshold and unit when relevant, reference-set version, and aggregation logic.
Retain the source report/proposal identifier, section/table, source text where
permitted, responsible study group, curator, review status, and effective dates.

Create a new version when a rule changes; record supersession instead of
overwriting the old record. Distinguish normative, descriptive, and inferred
content. A future merged knowledge-base product should be separate from the
class-oriented VTDC core release.
