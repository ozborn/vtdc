# Executable rules

Reserved for the future DSL and SHACL/other structural validation described in
the ViralTaxonomy framework. No rule engine is implemented in this scaffold.

Map rule fields to ontology identifiers after the required relation vocabulary
and instance model are reviewed. Specify numerical units and scales, operators,
comparison methods, reference sets, AND/OR composition, supporting evidence,
exceptions, and behavior for missing or uncertain observations.

OWL classification describes semantic relationships; it does not run BLASTP,
calculate sequence distances, or execute a taxon assignment procedure. Add an
independent evaluation test suite when those capabilities are implemented.
